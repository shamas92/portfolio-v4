# Shamas Ur Rehman — Portfolio v4

A personal portfolio built from scratch with a design-system-first workflow
(`PRODUCT.md`, `DESIGN.md`, the impeccable skill). Next.js 16.4.6, React
19.3, TypeScript, Tailwind CSS 4.3.3, MDX case studies, lucide-react icons.

Product truth lives in `PRODUCT.md`. The visual system lives in `DESIGN.md`
(written at finish from the built world; the working draft is the direction
contract in `.impeccable/surfaces/`).

## Run, build, deploy

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm run start
```

Deploy: import into Vercel (framework preset: Next.js).
